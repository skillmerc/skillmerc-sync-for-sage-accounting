# Skillmerc Sync for Sage Accounting (WooCommerce)

Send paid WooCommerce orders to Sage Accounting as a customer, a sales invoice with VAT per line, and a payment.

**Download:** see [Releases](https://github.com/skillmerc/skillmerc-sync-for-sage-accounting/releases/latest) (install the zip under Plugins > Add New > Upload). Setup guide: https://skillmerc.github.io/sage-accounting-woocommerce/

This build does not update itself. The plugin has been built for the WordPress.org directory; once it is listed there, install it from WordPress.org to get updates.

The full description, setup steps, limits and FAQ are in [readme.txt](readme.txt).
